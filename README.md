# Firewall Operations

Учебный браузерный тренажёр по основам настройки и проверки межсетевого экрана Linux.

## О проекте

Firewall Operations — учебный проект, предназначенный для ознакомления с основными принципами настройки межсетевого экрана в Linux и закрепления практических навыков работы с правилами фильтрации сетевого трафика.

Тренажёр ориентирован на выполнение последовательных практических заданий, ручной ввод команд и проверку результатов их выполнения.

## Цель проекта

Основная цель проекта — предоставить учебную среду, в которой обучающиеся могут изучать базовые принципы работы межсетевого экрана, выполнять задания по его настройке и контролировать правильность выполнения команд.

## Основные возможности

- Последовательное выполнение практических заданий.
- Ручной ввод команд в интерфейсе, имитирующем терминал Linux.
- Проверка выполнения заданий.
- Контроль ошибок при выполнении практики.
- Оценивание результатов.
- Формирование итоговых результатов обучения.
- Ограничение вставки команд из буфера обмена в поле ввода тренажёра.

## Используемые технологии

- HTML
- CSS
- JavaScript
- Linux
- UFW (Uncomplicated Firewall)

## Учебная направленность

Проект предназначен для использования в образовательных целях при изучении:

- основ сетевой безопасности;
- межсетевых экранов;
- правил фильтрации сетевого трафика;
- базового администрирования Linux;
- принципов контроля сетевого доступа.

## Особенности работы

Тренажёр предоставляет интерфейс для выполнения заданий и проверки вводимых команд. Выполнение практики предполагает самостоятельный ввод команд обучающимся.

Ограничение вставки из буфера обмена реализуется на уровне браузерного интерфейса и предназначено для повышения самостоятельности выполнения учебных заданий. Оно не является полноценной защитой от всех способов обхода ограничений браузера.

## Запуск

Тренажёр может быть размещён на GitHub Pages и доступен через веб-браузер при соответствующей настройке репозитория.
