# Firewall Operations

Браузерный учебный тренажёр по базовой настройке UFW в Debian. Команды вводятся вручную в симуляторе; реальная ОС и сеть не изменяются.

## Состав
- `index.html` — тренажёр для публикации через GitHub Pages.
- `Методичка_Firewall_UFW.docx` — методичка для студентов: настройка UFW и контрольные проверки в изолированной лаборатории Kali/Debian.

## Публикация на GitHub Pages
1. Создайте репозиторий `firewall-operations`.
2. Загрузите все файлы в корень репозитория (`index.html`, `README.md`, методичку).
3. В Settings → Pages выберите Deploy from a branch, `main`, `/ (root)` и сохраните.
4. После публикации адрес будет `https://<username>.github.io/firewall-operations/`.

## Ограничения
Тренажёр моделирует команды и результаты; он не запускает команды ОС, не сканирует сеть и не является защитой от обхода средствами браузера/ОС. Контрольные тесты внутри интерфейса — симуляция. Реальные проверки проводите только в разрешённой изолированной лаборатории.
